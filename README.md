# tnr-system

I designed an embedding system with a face recognition module for a cat cage in hight school. As the leader of our high school Cat Lovers Association, I was determined to fix a flaw in TNR (trap-neuter-return) work: traditional cages often trapped neutered cats or other animals by mistake. My idea was to design a cage that could recognize specific cats and close its door automatically. After analysis, there are 3 important parts: face recognition, connection with camera, connection with wifi relay. 

For recognition part, I was led to a GitHub repository using ResNet-50 for cat feature recognition. Reading its documentation, I was struck by how gradient descent, cost functions, and iterative convergence – concepts I had only encountered in theory - directly shaped a working system. Modifying the model introduced me to convolutional neural networks: how inputs transform layer by layer, how features are mathematically extracted, and how statistical decision theory guides decisions under uncertainty. The training, customizing and implementation of this model is the hardest part in this project.

For connection with the camera, I bought a WIFI camera with RTSP protocol. The camera is for transferring videos to main program. The main program screenshots every 3 seconds and detects whether there is action happened by comparing the similarity between photos. Then if an action has detected, the cat recognition module is called to recognize whether this is the cat we want to capture by comparing the similarity with photos in database. 

For connection with wifi relay, if recognition determines the target cats have appeared in cage. Connection module is called. A network transfer is made first (to receive video, the device was linked to camera's WIFI, now it needs to link to relay's WIFI.) Then a signal(extracting from their GUI, pretty hard to get the correct signal) is sent to the relay. Then, the door will be shut and the cat is captured.
